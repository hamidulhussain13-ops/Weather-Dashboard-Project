# 🌦️ Weather Dashboard Project

A simple and interactive Weather Dashboard application that fetches real-time weather data and displays temperature, humidity, wind speed, and weather conditions for any city.

---

## 🚀 Features
- 🌍 Real-time weather data for any city  
- 🌡️ Temperature, humidity, and wind speed display  
- ⛅ Dynamic weather icons based on conditions  
- 🔍 City search functionality  
- 📱 Responsive UI design  

---

## 🛠️ Tech Stack
- Python  
- Streamlit  
- OpenWeather API  
- Requests  
- Pandas

## ⚙️ How It Works
1. User enters a city name  
2. API call goes to OpenWeather  
3. Weather data is fetched in real-time  
4. Data is displayed in a clean dashboard format
